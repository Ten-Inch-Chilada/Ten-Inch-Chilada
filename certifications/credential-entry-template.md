# Credential entry template

Copy this file for each certification after it has been earned. Replace the fields below with the issuer’s details before publishing the entry.

| Field | Value |
| :--- | :--- |
| Certification | Exact credential name |
| Issuer | Issuing organization |
| Earned | Month and year |
| Verification | Public issuer or badge verification URL |
| Expiration | Date, or “Does not expire” if the issuer confirms this |
