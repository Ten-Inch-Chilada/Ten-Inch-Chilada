## Structure for a completed project

Each future project should explain:

1. **Context:** the fictional or authorized scenario and the question being explored.
2. **Scope:** the systems, processes, or requirements included.
3. **Method:** how the exercise was approached and what assumptions were made.
4. **Deliverables:** the assessment, policy, register, mapping, or evidence checklist produced.
5. **Reflection:** what was learned and what should improve next time.

Only mark an exercise complete once its documentation and deliverables are ready to review.
